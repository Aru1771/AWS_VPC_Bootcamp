Module 1: What is a Network?
==================================
Before AWS, before VPCs, before cloud networking, we need to understand what a network actually is.

Imagine this situation

You have two laptops.

Laptop A

Laptop B

Can they communicate?

No.

Because there is no connection between them.

Now connect them using a cable.

Laptop A  ------------------  Laptop B

Now they form a network.

Definition

A network is a group of devices connected together so they can communicate and exchange data.

Examples:

Home Wi-Fi network
Office network
College network
Internet (the world's largest network)
AWS VPC (your private cloud network)

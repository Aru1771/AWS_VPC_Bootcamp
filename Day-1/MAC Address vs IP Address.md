MAC Address vs IP Address
=========================

| MAC Address                       | IP Address                   |
| --------------------------------- | ---------------------------- |
| Physical hardware address         | Logical network address      |
| Assigned to the network interface | Assigned by DHCP or manually |
| Used within a LAN                 | Used across networks         |
| Example: `00:1A:2B:3C:4D:5E`      | Example: `192.168.1.10`      |

What is an IP Address?
----------------------
An IP address is a unique logical address assigned to every device on a network.

Think of it like a house address.

Without an address, nobody knows where to deliver the data.

Example:

192.168.1.10

or

10.0.0.15

Why Does Every Device Need a Unique IP?
----------------------------------------

Suppose two laptops have the same IP:

Laptop A → 192.168.1.10

Laptop B → 192.168.1.10

Now a server sends data to:

192.168.1.10

Which laptop should receive it?

Nobody knows.

That's why each device in the same network must have a unique IP address.
